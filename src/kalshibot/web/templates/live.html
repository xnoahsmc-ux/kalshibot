How to go live

When you run kalshibot run the live loop pulls open markets every POLL_SECONDS, rebuilds per-market history, asks the ensemble for a probability + dispersion, applies the dispersion-damped Kelly fraction, and (unless DRY_RUN=true) sends a limit order at the current quote, subject to the per-genre exposure cap.
