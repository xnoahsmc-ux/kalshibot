How this works

The live feed pulls open markets from Kalshi, appends a rolling MarketHistory per ticker, and asks the saved ensemble for a probability. Suggestions are gated by minimum edge, dispersion cap, and per-genre exposure (configured in .env). This page is read-only preview; actual order placement only happens when you run kalshibot run with DRY_RUN=false.

Troubleshooting
  • Click Auth check to verify your key ID + PEM path load correctly.
  • 401 → signature rejected. Re-check that KALSHI_API_KEY_ID matches the PEM you issued.
  • 403 Host not in allowlist → your network egress is blocked; try from a normal connection.
  • No signals → run a backtest first; without a saved ensemble every signal stays flat.
  • Empty table for a while → Kalshi poll is slow, give it 10-30 seconds after starting.
