Getting Kalshi API credentials
Required for live data
  1. Sign in at kalshi.com, go to Account → API Keys.
  2. Create a new key. You'll get a UUID (the Key ID) and a PEM file.
  3. Save the PEM to secrets/kalshi_private_key.pem in this folder.
  4. Put the Key ID in .env as KALSHI_API_KEY_ID.
  5. Restart the server, then on the Live page click Auth check.

Credentials are read from environment variables on startup; this page just helps you build the .env block. Nothing is written to disk by the server.
